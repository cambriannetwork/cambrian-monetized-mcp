# 🤖 Cambrian AgentFi Monetized MCP Studio

An interactive AI Agent testing environment, **Model Context Protocol (MCP) Server**, and **X402 Micropayment Protocol Simulator** for **Cambrian Network**.

---

## 🌟 Key Features

- 💳 **X402 Micropayments Protocol**: Atomic $0.03 USDC settlement on Base Mainnet for AI Agent API queries.
- 🤖 **Financial Intelligence MCP Tools**: Real-time wallet flow analysis, lending yield aggregator, and AI sentiment scoring.
- 🌐 **Interactive Web Studio**: Agent terminal and X402 payment ledger visualizer on `http://localhost:3418`.
- ⌨️ **Universal CLI (`cambrian-mcp-cli`)**: Terminal utility for requesting X402 challenges and executing paid MCP calls.

---

## 🚀 Quickstart

```bash
# Launch MCP Studio
npm start
# Open http://localhost:3418

# Or run via CLI
node bin/mcp-cli.js tools
node bin/mcp-cli.js call get_financial_intelligence
```
